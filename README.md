Benvenuto nei file d'installazione ufficiali di ZetaCraft Hub!
Questo archivio contiene l'applicazione mobile ultra-leggera in stile 
Liquid Glass azzurrato trasparente, ottimizzata a 60 FPS stabili per 
tutti i dispositivi Android e iOS della community.

---

📋 1. INFORMAZIONI SUL FILE APK (ANDROID)
- Nome File: zetacraft_hub.apk
- Dimensione: Meno di 811 Kilobyte (Record assoluto di leggerezza!)
- Requisiti minimi: Qualsiasi smartphone Android con almeno 4 o 8 GB di RAM.
- Autonomia di rete: I dati di gioco e il Server Status sono ospitati 
  sui nodi sicuri di fps.ms e comunicano a specchio col Survival 1.21.11.

---

🛠️ 2. GUIDA DI SBARCO PER AGGIRARE IL BLOCCO DI GOOGLE (IMPORTANTE)
Sui telefoni Android più recenti, Google Play Protect potrebbe mostrare 
un avviso di sicurezza visivo sul monitor definendo l'app come "Sconosciuta" 
solo perché è un file APK indipendente creato nei laboratori di ZetaLabs 
e non è ancora caricato a pagamento sul Play Store.

Segui questi 3 passaggi del dito per sbloccare l'installazione:
1. Clicca sul file scaricato sul display per far partire l'avvio.
2. Quando appare il banner di blocco di Google, NON premere "OK".
3. Clicca sulla scritta piccola "Maggiori informazioni" o "Dettagli", 
   quindi premi sul tastone "INSTALLA COMUNQUE". Il gioco è fatto!
L'applicazione si aprirà all'istante mostrando il pop-up interattivo 
di benvenuto a zero errori nella console!

---

🌐 3. SCORCIATOIA VELOCE PER UTENTI IPHONE (iOS)
Gli utenti Apple non devono installare file esterni sul proprio display:
1. Apri il browser Safari dal tuo iPhone.
2. Inserisci il link web ufficiale del network fornito da fps.ms (https://zetacraft.hostedbyfps.com).
3. Clicca sul tasto centrale di condivisione di Safari (l'icona col quadrato 
   e la freccia verso l'alto).
4. Seleziona la voce "Aggiungi alla schermata Home".
L'icona in Liquid Glass apparirà sul tuo desktop di iOS, funzionando 
in modo fluido e burroso a specchio come una vera applicazione di sistema!
